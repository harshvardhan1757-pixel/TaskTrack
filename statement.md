# DeadlineX — Project Statement

## 1. Problem

College students often have to manage multiple assignments, quizzes, projects, and academic tasks from different subjects at the same time. These tasks usually have different deadlines, priorities, and completion statuses.

Managing everything manually can make it difficult to identify:
- Which assignments are due soon
- Which tasks are already overdue
- Which tasks should be given higher priority
- How much academic work is currently pending
- How much of the assigned work has been completed

DeadlineX is designed to provide a simple command-line solution for organizing academic assignments and helping students understand their current workload.

---

## 2. Scope

The scope of DeadlineX is to provide a Java-based academic task management system that allows students to create, manage, search, and analyze their assignments.

The system focuses on:

- Creating and storing assignment information
- Updating and deleting assignments
- Tracking assignment deadlines
- Identifying overdue and upcoming assignments
- Managing task priority and completion status
- Searching and filtering assignments
- Analyzing the student's academic workload
- Generating a summary report
- Saving assignment data using local file storage

The project is designed as a command-line application and does not require an external database or online service.

---

## 3. Target Users

### Primary Users

**College and university students**

DeadlineX is mainly intended for students who have to manage multiple academic assignments and deadlines across different subjects.

### Suitable Use Cases

The system can be used by students to:

- Keep track of assignments from different subjects
- Check upcoming deadlines
- Identify overdue work
- Prioritize important assignments
- Monitor completed and pending tasks
- Understand their overall workload

---

## 4. High-Level Features

### Assignment Management
- Add new assignments
- View all assignments
- Update assignment details
- Delete assignments
- Mark assignments as completed

### Deadline Tracking
- Display overdue assignments
- Identify assignments due within the next few days
- Display upcoming assignments
- Calculate remaining days for deadlines

### Search & Filtering
- Search assignments by title
- Search assignments by subject
- Filter assignments by priority
- Filter assignments by completion status

### Workload Analysis
- Calculate total assignments
- Count completed and pending assignments
- Identify overdue tasks
- Identify tasks that are due soon
- Count high-priority assignments
- Calculate completion percentage
- Determine an overall workload level

### Report Generation
- Generate a summary of academic tasks
- Display completion statistics
- Display priority distribution
- Provide a quick overview of the student's current workload

### Data Persistence
- Save assignment information locally
- Load previously saved assignments when the application starts
- Maintain data between program executions

### Input Validation
- Validate required fields
- Validate dates
- Validate priority values
- Validate assignment status
- Handle invalid user input

---

## 5. Project Objective

The main objective of DeadlineX is to provide students with a simple and organized way to manage academic assignments while also giving them an overview of their workload.

The project demonstrates the use of Java programming concepts such as:

- Classes and Objects
- Object-Oriented Programming
- ArrayList and Collections
- Methods and Modular Programming
- Conditional Statements and Loops
- Exception Handling
- File Handling
- Date and Time API
- Input Validation

---

## 6. Expected Outcome

After using DeadlineX, a student should be able to maintain a structured list of academic assignments, quickly identify important deadlines, track their progress, and understand their current workload through the generated analysis and report.

The application aims to make academic task management simpler, more organized, and easier to monitor through a single command-line system.
