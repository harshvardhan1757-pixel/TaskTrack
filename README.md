# TaskTrack - Student Assignment & Deadline Management System

## Project Overview

TaskTrack is a Java-based console application that helps students manage assignments, track deadlines, analyze workload, and generate reports efficiently.

## Features

- Add Assignment
- View Assignments
- Update Assignment
- Delete Assignment
- Mark Assignment as Completed
- Search Assignments
- Filter by Priority
- Filter by Status
- Deadline Tracking
- Due Soon Detection
- Overdue Detection
- Workload Analysis
- Report Generation
- File-Based Data Storage

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- File Handling
- VS Code
- Git & GitHub
